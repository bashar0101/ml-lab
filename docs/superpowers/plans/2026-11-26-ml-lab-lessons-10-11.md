# ML Lab: Lessons 10–11 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship lesson 10 (Neural Network) and lesson 11 (Backpropagation), one branch each, merged to `main` and pushed when green.

**Architecture:** A small shared multilayer-perceptron engine (`src/lessons/shared/mlp.ts`) with explicit forward and backward passes that return every intermediate value, so scenes can draw activations and gradients. Lesson 10 records training snapshots (decision map + network) over epochs; lesson 11 records one training step layer by layer (forward, loss, backward, update) and then gradient sizes per layer over a few epochs. All other patterns as Plans 1–3.

**Spec:** `docs/superpowers/specs/2026-11-26-ml-lab-design.md` (§6 rows 10–11). Plans 1–3 in `docs/superpowers/plans/`.

## Review Focus

1. **Exploding/vanishing values** (large learning rate, sigmoid deep stacks): no NaN in frames or SVG; diverged frame stops the run.
2. **Network shape extremes** (1 neuron, 3 layers × 8 neurons): diagram stays legible; no layout overflow.
3. **Text vs behaviour**: every claim in the story/break-it (e.g. "one neuron can only draw a straight line", "early layers learn slower with sigmoid") is pinned by a probe test.
4. **Stale data** after invalid edits: no old network map over new points.
5. **Frame count**: training snapshots capped (≤ 120 frames).

### Task 1 (branch `lesson/neural-network`): shared MLP engine

`src/lessons/shared/mlp.ts` (+ test), `tools/fixtures/mlp.py`, fixtures in `src/lessons/neural-network/fixtures.json`.

```ts
type Activation = "tanh" | "relu" | "sigmoid";
interface Mlp { sizes: number[]; activation: Activation; W: number[][][]; b: number[][] }   // W[l][j][i]: layer l, neuron j, input i
function initMlp(sizes: number[], activation: Activation, seed: number): Mlp      // N(0, 1/fan_in) via mulberry32 Box–Muller (tanh/sigmoid), N(0, 2/fan_in) (relu); biases 0
function forward(net: Mlp, x: number[]): { z: number[][]; a: number[][] }       // a[0] = x; output layer = sigmoid
function backward(net: Mlp, f: ReturnType<typeof forward>, y: 0 | 1): { dz: number[][]; dW: number[][][]; db: number[][] }   // log-loss
function trainEpoch(net: Mlp, X: number[][], Y: (0 | 1)[], lr: number): { net: Mlp; loss: number; gradNorms: number[] }   // full batch, mean gradients
```
- [ ] Fixture: init weights for sizes [2,3,1] seed 1 (tanh) and [2,4,4,1] seed 2 (relu); forward/backward values for one point; weights after 1 and 20 full-batch epochs on the fixed 12-point dataset (lr 0.5) → tests (exact match 1e-10; numerical-gradient check of `backward`; no NaN with lr 50; gradNorms length = layers) → implement → commit.

### Task 2 (same branch): neural-network lesson

### Tasks 3–4 (branch `lesson/backpropagation`)

Default network [2,3,1] tanh with fixed seed; one training example (the probe point) for the detailed step, then full-batch epochs for the gradient-size chart.
Trace: `init` → `forward-1`, `forward-2` (layer by layer, values on nodes) → `loss` → `backward-out` (dL/dz at output) → `backward-hidden` (dL/da, dL/dz) → `grads` (dL/dw on every edge) → `update` (weights after one step) → then `epoch` frames recording per-layer gradient norms for 40 epochs on the whole dataset → `done`. Params `{ depth: 1–5 hidden layers of 3, activation, learningRate }`.
Scene: network diagram with numbers (node values on forward frames, gradients on backward frames, edge labels for dL/dw on `grads`), a "flow" arrow left→right on forward, right→left on backward; right/bottom panel: bar chart of gradient size per layer (log scale) on epoch frames.
Story (6): `guess` (forward) → `how-wrong` (loss) → `blame-output` → `blame-hidden` (chain rule) → `every-weight` (grads + update) → `vanishing` (deep sigmoid chart).
Break it: 5 sigmoid layers — the first layer's gradient is ~100× smaller than the last.
- [ ] Fixture (numbers for the detailed step; per-layer gradient norms for depth 5 sigmoid after 1 epoch) → tests (chain-rule numbers, numerical gradient check, vanishing claim ratio > 10) → scene/content → merge → push.
