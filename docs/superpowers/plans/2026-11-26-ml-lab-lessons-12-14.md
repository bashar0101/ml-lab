# ML Lab: Lessons 12–14 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship lesson 12 (Convolutional Neural Network), 13 (Recurrent Neural Network) and 14 (Attention & Transformers), one branch each, merged to `main` and pushed.

**Architecture:** Same `LessonModule` + trace pattern. Lessons 12–13 ship small weights trained offline by NumPy scripts in `tools/train/` (committed, deterministic, NumPy only); the browser recomputes every activation from those weights and the student's input, and the trace records each step of that computation. Lesson 14 uses hand-set weights (stated openly in the lesson) chosen to make the mechanics visible.

**Spec:** `docs/superpowers/specs/2026-11-26-ml-lab-design.md` (§6 rows 12–14).

## Global Constraints

- All Plans 1–4 constraints (static, text in `content/en`, Python + pseudocode, keyboard paths, ≤ 200 KB JS per lesson page excluding weight JSON, branch per lesson merged `--no-ff` + pushed, no Claude trailers, `stale` honoured, "not yet" chips as `undefined`).
- **No downloaded datasets.** Digits are generated from a hand-drawn 5×7 font with random shifts and pixel noise (`tools/train/digits.py`); RNN strings are generated.
- Every claim in story/break-it/article is pinned by a probe test or measured in the ledger.
- Weight JSON files ≤ 20 KB each.

## Review Focus

1. **Text vs behaviour** (as in every batch): measured claims only.
2. **Drawing input** (empty canvas, every pixel on, single pixel): finite outputs, sensible probabilities.
3. **Long inputs** (RNN strings up to 40 letters, attention sentences up to 12 words): layout stays legible, frames bounded.
4. **TS forward = Python forward** on fixture inputs (exact to 1e-9).
5. **Keyboard path for drawing** the digit (grid of toggle buttons).

### Task 1 (branch `lesson/convolutional-neural-network`)
`tools/train/digits.py` (font, generator, numpy CNN: conv 4×3×3 valid → ReLU → max-pool 2×2 → dense 36→10 softmax; Adam; seed fixed), writes `src/lessons/convolutional-neural-network/weights.json` + `fixtures.json` (forward outputs for 5 sample images, test accuracy, accuracy on corner-shifted digits). TS: `cnn.ts` forward with every intermediate; trace: `init` → 36 `conv` frames for the chosen filter (window position + dot product; tags `conv-first`, `conv-done`) → `relu` → `pool` → `maps` (all four filters) → `dense` (class probabilities) → `done`. Scene: input grid with numbers, sliding window, kernel grid, feature map filling in, pooled map, probability bars. Lab: 8×8 toggle-button grid (keyboard), presets (each digit, shifted, noisy, blank), filter chips (4 learned + "vertical edge" + "blur" hand kernels for the picture only — prediction always uses learned filters). Story: `pixels` → `kernel` → `slide` → `feature-map` → `pool` → `decide`. Break it: measured (e.g. digit drawn in a corner / extra noise).

### Task 2 (branch `lesson/recurrent-neural-network`)
`tools/train/rnn.py`: vocab `a`–`h`, task "did the string start with **a**?" (first letter a or b, the rest c–h), tanh RNN hidden 6, BPTT on lengths 2–12; writes weights + fixtures (hidden states for a fixed string; accuracy by length 2…40). TS: `rnn.ts`; trace: `init` → one `read` frame per letter (tags `first-step`, `step-3`) → `predict` (tag `done`). Scene: unrolled cells left→right (letter in, hidden state as a coloured strip of 6 cells, arrows), probability gauge, accuracy-by-length chart (from fixture). Lab: text box (letters a–h, max 40), presets (short, medium, long). Story: `order` → `memory` → `unroll` → `update` → `answer` → `fading`. Break it: long strings → measured accuracy drop.

### Task 3 (branch `lesson/attention-transformers`)
Hand-set 2-head self-attention over a small vocabulary (≤ 16 words): embeddings (semantic features) + sinusoidal positional encodings; head 1 "who refers to whom" (semantic query/key), head 2 "neighbours" (positional). Trace: `init` → `embed` → `scores` (raw q·k for the selected word) → `softmax` → `mix` (weighted values) → `all-words` (full attention matrix) → `done`. Scene: tokens row, Q/K/V vectors for the selected token, attention arcs, heat-map matrix, output vector. Lab: sentence presets ("the cat chased the dog and it ran", …), word picker (keyboard), head chips, "positions on/off". Story: `context` → `query-key` → `softmax` → `mix` → `heads` → `order`. Break it: positions off → "it" splits its attention between both nouns (measured).
